# foundry-agent-gateway

A local MCP server that lets AI agents work inside a Foundry VTT world, together
with the Agent Gateway Foundry module.

```sh
npx foundry-agent-gateway
```

This starts a stdio MCP server. Add it to your MCP client as a command:
`npx foundry-agent-gateway`. Use `--help` for options and `--version` for the
installed version.

Requires Node 22.13 or newer.

Setup, the Foundry module and full documentation:
https://github.com/AindriuB/agent-gateway#readme
